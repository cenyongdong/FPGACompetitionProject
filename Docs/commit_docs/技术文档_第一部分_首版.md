## 功能与特性

本作品是一套基于Wi-Fi信道状态信息（CSI）的嵌入式多人三维姿态感知与展示系统。在复旦微悟净Lite平台上，处理系统（PS）完成CSI预处理与人物后处理，神经网络处理单元（NPU）执行姿态模型，可编程逻辑（PL）驱动本地HDMI，最多展示3人、每人14关节的三维骨架。PC提供独立的多视角观察界面，无需参与板端推理或本地显示控制。

此前实时链路版本已完成三接收节点直连板端、有限连续运行、接收节点断线恢复及PC离线测试。当前交付采用原 epoch99 模型，保留实时采集和官方预采 CSI 两个接口；默认从板端文件顺序读取官方训练集单人、双人、三人片段，约 10／9／9 秒，在板端执行实际推理。TopK=3 后严格筛选 score >0.2；片段切换共用同一 SDK 生命周期，训练集展示不计独立测试精度。系统支持最新完整窗口调度、异步有界记录和安全停止；显示服务初始化后、首份结果到达前显示七色条。

## 应用领域

作品面向室内非接触人体姿态可视化、无线感知教学及嵌入式人工智能验证。系统以CSI为推理输入，不依赖RGB图像或人体佩戴设备，可为需要减少图像采集的场景提供技术验证平台。

在教学与研发中，可使用同一板端系统比较单人、双人、三人片段的姿态输出、后处理与显示效果，研究无线数据接入、神经网络部署和硬件显示的协同关系。独立PC界面便于多视角观察，本地HDMI便于现场展示。已完成的数据集演示可直接用于上述教学和验证。

## 主要技术特点

系统采用PS、NPU与PL协同架构。输入按3接收机×3天线×30载波×20时刻组织，经幅度和相位预处理形成180×60特征。基于Person-in-WiFi 3D构建180查询候选模型，通过ONNX和Icraft完成FP16部署，保留全部候选输出，由PS执行人物选择。

PS完成Top3与置信度筛选、人物去重、跨帧关联、局部异常门控和One Euro滤波，关联状态与显示平滑独立更新。HDMI与PC共用同一组后处理姿态，HDMI采用RGB565双缓冲及明确的换帧、停止确认。推理由单一SDK线程管理，PC传输和诊断记录异步执行；缓存设定容量上限，过载时淘汰尚未处理的旧数据。当前默认采用PS滤波，复用已通过物理资格与有限板测的位流。

## 主要性能指标

| 项目 | 指标或实测结果 |
|---|---|
| 姿态输出 | 最多3人，每人14关节 |
| HDMI 扫描配置 | 1920×1080 RGB565，设计扫描为 60 Hz；显示规格限制见[历史说明](../../software/pose180_pipeline/resident/WINDOW-RECOVERY.md#显示规格限制)，不作为屏幕兼容验收 |
| 历史独立模型处理 | 平均11.14 ms，不含采集与显示 |
| 历史新结果速率 | 15 Hz数据集输入下13.75～14.86帧/秒 |
| 最新 r3 演示记录 | 3 片段、420 帧新推理／HDMI 采纳／PC 发送，正常退出 |
| 历史六片段验证 | 6 片段、867 个不同样本、3024 次新推理 |
| 历史实时链路 | 30分钟、15310次新推理 |

历史性能项属于对应版本与负载，不作为最新 r3 的重新测量。最新结果和证据见[项目进度](../../PROJECT-PROGRESS.md)；扫描刷新率不等于推理帧率，PC 发送不等于每帧网页绘制，长期和姿态精度仍未验收。

## 主要创新点

1. 基于公开模型完成180查询结构及NPU部署适配，消除图内TopK、GatherElements和ScatterND中间主机计算，减少PS与NPU交接环节。
2. 构建板端推理与HDMI闭环，使PC观察、诊断记录独立消费结果，并以有界缓存支持过载降级。
3. 将人物关联与显示平滑解耦，以统一姿态帧驱动HDMI和PC，实现同源双端展示。

## 设计流程

确定功能与验收范围 → 准备公开数据和基础模型 → 调整并训练180查询模型 → ONNX导出与Icraft转换 → 集成PS、NPU及PL接口 → 实现后处理与双端显示 → 完成软件测试、RTL仿真、布局布线及时序核查 → 开展有限实板与故障恢复测试 → 固化默认BOOT和恢复备份。

当前采用已合格位流开展数据集演示，软件与硬件验证结果分别记录。
