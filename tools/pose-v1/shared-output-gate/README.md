# 共享细化输出门检

依据 [ADR_48](../../../ADR/ADR_48.md)，仅用于固定共享 FP16 候选。`shared_output_gate.hpp` 是独立、无 SDK 依赖的比较模块：全部 100 分数字节相同，全部输出和参考有限，全部 100×14 关节同槽三维欧氏偏差不超过调用者明确给出的毫米上限。当前固定部署入口明确传入用户批准的 `3.0`；模型单位按 1000 转毫米。

模块只返回比较结果，不修改输出、参考、排序或运行时同步。输入逐位、模型身份、SDK／索引／超时错误以及先保存再比较由诊断入口原有契约维持。正式核心及旧 DATA 路径不接入本例外。

`selftest.cpp` 包含实际执行的 12 组边界和拒绝检查；新 ARM 入口和完整源码归档见 [本轮证据](../evidence/shared-gate-policy-20261015-r1/REPORT.md)。三窗中前两窗通过新门检，第三窗最大关节差 5.524271728 mm，超限停止；实现门检不表示模型已经通过。
