# 共享细化候选 3 mm 门检变更与实际复验

执行日期：2026-10-15。**已按用户明确指定，将固定共享 FP16 候选的姿态门检改为全部候选最大关节三维欧氏差 ≤3 mm，分数和输入仍逐位比较。新一轮实际执行了原计划三个窗口，前两窗通过，第三窗超限后停止，未重试。** 该候选仍未通过本轮完整数值验收。

## 决策、原因与范围

用户先要求接受此前 1.953 mm 差异并放宽门检，随后明确：“最大误差可以定在3mm以内”。本轮落实为 `sqrt(dx²+dy²+dz²) × 1000 ≤3.0 mm`，含等号，覆盖全部 100 个候选、每个候选的 14 个关节，维持原槽位对应。采用 double 计算差和向量长度，不将输出舍入后再比较，不做候选重匹配。

用户提出的“算法改造使 NPU 硬件物理变化而产生物理偏置”记录为**待验证假设**。目前已确认计算图、矩阵形状及编译指令发生变化，FP16 结果不再逐位一致；SDK／BOOT／器件保持。尚未定位具体低精度计算步骤，也没有证明物理结构变化或固定偏置。用户接受误差范围的决定与根因证明分别记录，见 [ADR_48](../../../../ADR/ADR_48.md)。

仅适用于 `model/piw24_shared-20261015-r1`：JSON SHA256 `a1395205eed11112ac0e23dacf8eec4c09d7dfec120e99b060a9361cb9c812cc`，RAW SHA256 `d235ec300f2872f1b78ce6101bc98fd2cc13c47a53fe99f76e045587148279dd`。权重、TopK、候选数、图与 RAW、SDK、数学核、预处理均未更改。MPJPE 继续报告实际增量；本次用户没有指定新的 MPJPE 硬门限。

原首次逐位失败及其清单／报告／源码／原值全部保留。旧 DATA 调查继续暂停，正式基线的逐位规则保持；本次不是对其他模型或旧 DATA 异常的通用豁免。
