# HDMI隔离候选模块

**当前已按用户要求暂停。** 恢复必须由用户明确唤醒，先读 [RESUME.md](RESUME.md)。

本目录包含独立时钟、AXI只读主机、跨时钟命令邮箱、帧地址控制及CSR bank。它是离线候选模块，尚未接入原PS/AI工程、FIFO与TMDS物理输出。原参考源码和当前BOOT不改。

本地CSR偏移仅定义候选契约，不是当前板端寄存器：0x00为ABI标识0x48444d01，0x04/08为地址/ID参数，0x0c发命令（0快照、1启动、2提交换帧、3停止、4清故障）。0x10/14/18/1c/20分别读最近原子响应的status、stopped ID、已采用地址、已采用ID、faults；0x24/28为提交/响应代数，0x2c为本地队列与错误。写命令必须完整字节掩码，外层总线必须遵守write_ready；PS侧需要单线程所有者及响应代数检查。

status位0为safe_idle，1运行，2读主机busy，3帧读活动，4有待采用地址，5等待burst完成，6已同步lock，7停止中，8已有当前地址，31为该命令被拒绝。命令响应不等于翻帧或停止完成，软件必须取得新快照核对采用ID或stopped ID和safe_idle。

邮箱为单命令握手，复位必须与封装AXI系统协调。safe_idle不是局部复位后可直接释放原在途缓冲的许可。停止排空依赖AXI slave最终响应，超时或缺失RLAST保持busy并报错，不能伪造完成。

已过模块行为验证、完整一帧背压验证及Procise原生综合；尚无布局布线、完整CDC/时序签核、PLL实测或实屏验收。详细范围、现存地址边界待查项和恢复顺序以RESUME为准。
