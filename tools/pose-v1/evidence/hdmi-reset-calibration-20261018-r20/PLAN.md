# r20 单次PL按键清零校准（执行完成，已回原BOOT、关闭）

实际1次候选、1次用户按键、1次回退，SDK加载／Open均0。按键后仍读回0/2/2，详见[REPORT.md](REPORT.md)。以下保留批准范围。

不等待偶发故障，先独立检验PL_KEY2能否实际清除观测器状态。复用同r9 BOOT和已构建、已通过5类测试的独立纯CSR ELF；包内只有两份BOOT和该ELF，不包含SDK子进程或加载父进程。无FPGA重编，六SDK只做文件身份核对，绝不加载／Open。参数见deploy/config.json。

请求1次同r9候选安装／启动；SSH恢复后先恢复原BOOT文件并完整读回。纯CSR严格从0采0→2，保存完整104字及初始五寄存器值。若ABI／代次有效、flags=0x19、窗口复位及六路AR/R和非OKAY计数均0，且属于健康空闲或已识别的HP2／HDMI全窗口返回背压，无设备占用，才允许用户按PL_KEY2／SW7一次约0.5秒松开。**健康空闲也允许按一次，是本包需要新增明确批准的范围。** 其它异常停止，不按键。

实际确认后只运行一次同一纯CSR程序，先完整保存ABI／长度／status/request/response；不为通过门检改用旧代次。初始不为0则无命令退出，得到“观测器状态未表现为归零”的原值；若归零才采0→2，比较返回通道。按键前后PS boot_id必须不变；不重按、不重试、不做SDK、DMA、推理、HDMI START／长期验证或文件系统修复，旧DATA仍暂停。按键可能重置MIG／PL DDR及相关逻辑，故严格无负载／无owner。

最后最多1次原BOOT回退并独立核验关闭。候选／原BOOT身份、备份、串口只接收、完整读回和25秒软监控沿用已执行流程；真实异常保存停止，不销毁正常进程。本地使用r17健康原值、r18故障原值及AR活动／owner／复位反例共5项门检通过，Python语法通过，硬件尚未执行。
