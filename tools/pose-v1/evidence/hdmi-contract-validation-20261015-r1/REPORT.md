# HDMI 寄存器实板核验与参考RTL行为验证

2026-10-15，主机工作目录 `D:/FPGACompetitionProject`。

## 实际结论

1. 项目本地 `BIT/30tai_lite_detpost` 的BOOT和bit与下载区指定版本逐字节相同；完整版产物不同。板端当前显示控制版本及默认寄存器特征相符，提升配套对应证据，但不是完整源码→实现产物证明。
2. 参考RTL固定1080p扫描在200MHz下实测仿真80.808081Hz，在6.734ns周期下60.000060Hz，均为2,073,600有效像素。当前实板像素／串行时钟和PLL lock仍未直接测量，80.81Hz不能写成现场根因。
3. 参考读帧状态机在持续FIFO背压下停留S_CHECK_FIFO，4096周期无完成；解除背压可继续完成。显示门控将高VS变低时会产生新读请求。
4. 参考AXI控制器在 `RVALID=1, RLAST=1, RREADY=0` 时仍给出FIFO写使能，并报告RD_DONE；该请求接受拍数为0。缺陷已在隔离仿真中复现，故简单导出RD_DONE或read_finish也不足以证明可以释放缓冲。
5. 用户最终更正并确认：显示器已连接，仍提示不支持当前时序。此前误点的“已有稳定画面”作废，不记为显示通过。

## 板端实际执行

使用既有FPAI ARM64 GCC／Icraft3.39.0交叉编译，只部署独立寄存器探针。入口 `FPGA/hdmi_validation/deploy_probe.py`，工作目录 `/tmp/hdmi-register-probe-20261015-r3`。固定ED25519主机密钥，凭证仅认证子进程内存，不出现在命令、环境或运行日志。先核验BOOT与六份SDK库，再核验传输binary SHA。

一次SDK探针进程预算10秒，实际0.083909秒、exit0。Device/icore身份匹配后先读frame_ctrl版本0x20230218，再读其余白名单配置，共12次显式显示寄存器读取。SDK原有初始化／析构照常执行，未声称私有生命周期内部绝对无写；探针没有应用层寄存器写、Session、模型加载、扫描帧分配、camera对象、reset或DMA启动。

板端日志日期与主机日期不同，SDK日志显示的2026-03-13不作主机实际执行日期依据。

## 仿真执行及边界

使用已安装XSim2019.1，仅进行行为仿真，独立ASCII工作目录 `.local/hdmi-contract-sim-20261015-rN`，每个编译／展开／仿真阶段预算120秒。无综合、实现、IP再生成或下载。DDR/FIFO占用和AXI slave是显式测试激励，未模拟真实DDR、完整异步FIFO IP、PLL锁定或TMDS物理链路。

原始color_bar、frame_fifo_read、video_rect_read_data、timing_gen_xy未改逻辑。aq_axi_master存在10项重复ANSI端口wire声明，XSim拒绝原文；仅在仿真副本删除这些声明，完整diff与原／副本SHA保存，状态机和表达式不改。原项目源码未修改。

- r1：编译过，展开因原模块缺省timescale与测试台混用失败，未仿真。
- r2：显式设缺省timescale后，原五项扫描／读帧控制验证全部通过，正常一帧32400个16-word burst，合计518400个64位字。
- r3/r4：新增AXI测试时因原源重复端口声明编译失败，两次原日志保留。
- r5：仅语法适配后AXI正常控制及缺陷已复现，但独立测试完成后的watchdog未禁用，10us终止；不称完整验证通过。
- r6：修正测试台watchdog条件后，编译／展开／仿真全部exit0，正常控制、AXI缺陷复现、FIFO背压／恢复、VS请求及两组扫描频率均得到预期结果。仿真wall约20秒，模拟时间约16.711744ms。**测试台通过表示验证/复现符合预期，不表示原DUT正确。**

最终日志、波形及语法差异：[仿真r6](../hdmi-contract-sim-20261015-r6/)。XSim结果不等于Procise实现或实板验收。

## 主机构建过程与停止条件

探针r1在访问Docker管道时被本机受限环境拒绝，尚未启动容器或连接板端。限制外只读inspect确认容器exited后，新r2核对既有SDK并编译；readelf显示通用Device API导致后端注册库被as-needed剔除，部署前拦截。新r3增加no-as-needed并设置ELF依赖硬检查，AArch64和ZG backend依赖均过后才部署。无失败板端负载重跑，r1/r2产物与日志保留。

任何超时、非零退出、BOOT/SDK/device版本不符或新增内核信息均保存现场并停止。未把代码准备或单次读取成功扩展为HDMI通过。
