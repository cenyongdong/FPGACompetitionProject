# 独立显示子进程后的接续方案

当前[可行性结果](DISPLAY-PROCESS-RESULTS-20261008.md)：实际独立程序、拥有值IPC及70正确前向/视频通过；5Hz输入33/33无覆盖，实测4.99165Hz、画面P95 262.21ms，严格≥5Hz未过。保留当前父子身份及原r2，不重复本轮测试代替新定位。

1. **先定位forward尖峰。** 当前invocation28/S11_12_329 aggregate forward221.61ms，原因未证。新隔离候选在SDK profiling关闭、同steady_clock和原帧协议下，有限采样op Host/ZG、桥等待/复制/CPU forward及final wait，记录是否和显示/IPC/编码时段交叠；父子和异步跨度分别报告，不能将ZG提交跨度当纯NPU时间。采样会引入开销，先Host/原三帧及同参考回归，诊断阶段不混作低日志性能验收。
2. **准备更长有界计量入口。** 当前每个显示子进程请求33、ready20秒、编码1000/marker10bit和客户端95秒限制明确；不能只加timeout。新入口设计有限统计/分段输出、传输身份、请求上限和正常停止，保留每个实际消费的来源及独立数值抽查/失败完整值。先有限负载再严格速率和延迟判断，不自动增加误差或速率容限、删尖峰、调整CPU数学/cache/NPU同步。
3. **扩展故障清理。** IPC断开/异常退出已Host验证；接入真实全链时进一步有限测试输入断流/超载/重连、显示子进程错误、慢RTSP客户端，确认父侧Engine直到编码/网络结束、子进程回收、设备/队列释放，无无界重开或任意P帧丢弃。
4. **首次启动单列。** 最后order7+为0且CmaFree约4MiB，本轮一次规整授权已消耗。先匹配MVX固件、页表、视频缓冲实际分配/DMA/MMU/cache/释放路径，制定资源预分配/常驻或安全CMA方案；无明确恢复选择不自动再规整/清缓存/重启，不猜加MOVABLE或扩大预留区。
5. 条件通过后再长期入口和30分钟，HDMI仍需当前BOOT匹配时序/scanout/停止接口及实屏。独立显示子进程目前只绘图/转换，不等于HDMI输出已实现。

优先下一批为尖峰定位和有界统计入口设计，不直接优化模型/图/新算子或零拷贝。尚未创建下一新修订、执行更长负载或改变本轮父子程序。
