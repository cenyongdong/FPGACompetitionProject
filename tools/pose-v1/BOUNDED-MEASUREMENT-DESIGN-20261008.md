# 更长有界计量入口设计

当前批先定位尖峰；本文件准备后续独立低日志入口的约束，尚未执行扩展负载。

| 契约 | 当前 | 新独立入口 |
|---|---|---|
| TCP单会话发送 | 33 | 103：3预热＋100计量，5Hz |
| 传输身份 | 100000–100032 | 100000–100102；固定27来源循环；越界拒绝 |
| worker渲染预算 | 33 | 103；单信用、容量2、拥有值不变 |
| 结果记录 | reserve33／cap33 | reserve103／cap103；记录输入、分数、姿态和来源 |
| 就绪后编码时间 | 20秒 | 30秒；1000帧／10bit标记不变 |
| VPU／Engine启动 | capture5秒／Engine60秒 | 保持；超时保存停止 |
| 网络／客户端 | 90／95秒 | 显式100／105秒；总外部180秒保持 |
| 内部算子记录 | 诊断最多32次 | 关闭；与本轮trace数据分开 |

模块边界：独立负载契约定义来源映射与预算；Receiver仅处理输入；显示worker仅绘图转换；Engine保持主线程所有权；编码线程独占VPU；网络事件循环独占live555。不得包含其他模块.cpp或复制CPU算法。

保留完整103套数值，严格逐位核对每个实际消费；消费/覆盖/显示/采样采用/重复分别计数，不以重复画面算新姿态吞吐。结果先保存再比较；异常保存已完成值并停止。大型NV12仅保存首帧、各不同来源、重复对照；其余解码画面按实际已保存分数/姿态由冻结renderer独立生成参考，明确标注为重建参考，不伪装为实测图像。实现前须调整视频核验器对该契约的处理，保留所有逐帧来源、PTS、NAL和码流哈希。

Host新增首尾身份、104越界拒绝、103预算及释放测试；之后新目录三窗回归、有限扩展负载。按实际完成时间计算速率和P95，保留所有尖峰，不改变数值或速率容限。105秒客户端仍须显式正常EOF／TEARDOWN；父进程等待所有worker及子进程退出后才销毁Engine。过载、断流和30分钟为后续独立门检。
