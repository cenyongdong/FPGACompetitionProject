# 第59轮、50轮180-query与原100-query三组对比

2026-10-23，Asia/Shanghai。完整测试集7,824帧，1／2／3人分别2,586／3,184／2,054帧；分数严格使用`score > 0.2`。原100-query epoch442和180-query epoch50复用既有数据，仅重新推理180-query epoch59。

**结论：第59轮的原口径MPJPE在三个人数组都比第50轮改善，但检出指标并未全面改善。** 2人组的数量不足、多报、疑似重复和阈值匹配MPJPE均变差；3人组数量不足略降，多报和疑似重复增加。与原100-query相比，第59轮各组两列MPJPE、200mm召回率和三个数量问题指标仍较差。

以下含斜线的单元格固定顺序为 **原100-query epoch442／180-query epoch50／180-query epoch59**。
