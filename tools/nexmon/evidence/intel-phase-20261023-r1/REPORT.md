# 论文原始与对齐CSI的只读相位核查

2026-10-23，按用户明确授权完成。**原始数据及对齐窗口中确有相位波动／多载波超差，但本次抽样未检出与RT-AC86U约1.8rad整带同向跳变同等强度、同等特征的事件。不能把两类现象直接归为同一原因，也不能据此认定路由器的大跳变不可避免。**

机器可读入口：[汇总](summary.json)、[完整结果](analysis.json)。没有修改服务器数据或源码、训练状态、模型、预处理数学及板端协议，没有连接路由器／Lite或启动采集。

## 数据与核查范围

Z盘实际映射`/public/cyd`；原始日志为`/public/cyd/rawdata/CSI/r1、r2、r3/data/*.dat`，时间文本位于各节点`time/*.txt`。对齐数据为`/public/cyd/Person-in-WiFi-3D-repo/data/wifipose/train_data/csi/*.mat`。

沿用此前子载波对应核查的固定9训练组／9会话：S11_01、S12_01、S13_07、S21_01、S22_01、S23_01、S51_01、S52_01、S53_02。每个会话检查3接收节点的完整日志，并复查此前预选的首／中／末三个20帧窗口，没有按相位结果选择样本。共27份原始日志、548,190条Intel记录，以及27个MAT文件的81个节点窗口。

MAT原存储为`(20,30,3,3)`、real／imag双精度字段，保留复数CSI，并非只有幅度。复用[原Intel解码器](../../host/audit_intel_reference.py)，按逐帧天线排列字段恢复物理接收链；27份时间文本行数均与对应CSI帧数一致。

本次比较同包链间相位差的相邻圆周变化。主诊断沿用相位步长>0.25rad、至少一半载波超差、圆周离散度<0.25rad；Intel为15／30。要求参与链的30个载波在相邻两帧均非零、接收时间递增且间隔<32.768ms；零值相位及跨时间缺口显式排除。没有插值、补帧或相位修正。

**该规则标记多载波超差，不保证这些载波全部同向旋转。** 正负混杂的低幅度相位噪声也可能触发。因此不能把每个标记都称为与RT相同的整带状态切换，或当作论文的硬件故障／模型准确度判据。

程序经既有`ssh gpu-server`进入已安装的PersonInWIFI环境，以`python -B -`从stdin运行，在服务器内存分析，只读打开原文件，未部署远程脚本或缓存。入口为[audit_intel_phase.py](../../host/audit_intel_phase.py)；进度和原生结果见[progress.log](progress.log)、[ssh.stderr](ssh.stderr)、[execution.json](execution.json)。SSH退出0、stderr为空，无常驻分析任务。五个小型定向检查覆盖固定相位、已知单链1.8rad旋转、纯正实数增益、长时间缺口及零值排除。

原始日志中至少一个链对触发的相邻比较共5,951次。这些只是按本轮规则检出的相位变化，不全是已证实的硬件异常。完整日志与短窗口观察时长不同，25／27和3／81不能相减计算去噪率，也不能外推全数据集发生率。

对齐后仍触发的文件是`S12_01_408`、`S12_01_499`、`S23_01_599`，均在第二接收节点。具体证据见[同帧幅度与相位](aligned-witness-strength.json)：

这些窗口保留原始复数值，说明时间对齐没有清除全部相位变化，也未见所核查窗口发生相位数值改写。该对应关系只覆盖本轮抽样，不是所有MAT导出过程的穷尽验证。

## 与RT大跳变的区别

在本轮满足非零及时间连续性条件的Intel主诊断标记中，共同相位步长最大约0.915rad，没有检出满足该定义且共同步长>1rad的事件。**这不证明整个论文数据集绝无大跳变**；非零条件排除了相位无定义的比较。

RT第一轮则已观察到约1.5～2.0rad的共同跳变、方向一致性约0.998，并与链0幅度状态变化相伴。另按与Intel相同的30个相对载波索引重算，RT三轮链对标记分别39／46／0、0／1／0、0／0／0，见[同30点诊断](nexmon30-comparison.json)；原56点结果不回写。

硬件、房间、人体活动、频率和量化格式不同，本次不是受控硬件优劣实验。论文存在弱链相位不稳，不足以证明RT约1.8rad整带状态切换普遍且必须接受。

## 现有预处理与结论边界

只读查看服务器`opera/datasets/wifi_pose.py`，在内存执行其中现有`CSI_sanitization`函数，没有导入模型或修改源文件。S11_01_10三个节点三个链对，校正前后链间相位差最大圆周差约4×10⁻¹⁵rad，见[预处理核对](preprocessing-pair-phase.json)。

该函数给各链去除同一载波线性项和公共偏置，这些公共项在同载波链间差分中抵消，因此不保证清除接收链间的突发相位差。时间戳对齐和相位预处理也不等价。

本轮确认训练输入对应原始复数中存在相位变化，且部分在对齐窗口保留；没有测量模型容忍范围、当前RT数据的识别精度或心率准确度。不能从论文数据有变化直接推断路由器当前输入一定可用。

下一步应分开处理弱幅度／量化相位不稳与RT整带幅相状态切换。前者需源质量诊断；后者仍优先核查同帧分链增益／射频／校准状态。本轮没有修改门槛或现有模型数学，没有新增实机操作。
