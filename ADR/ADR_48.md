# ADR_48：共享细化 FP16 候选采用 3 mm 有界数值门检

日期：2026-10-15。状态：用户已明确批准；实现与实测证据见下文链接。适用对象为共享细化后的固定 FP16 候选图，不改变正式旧基线或旧 DATA 调查的验收规则。

## 背景与用户决定

共享细化将同一帧重复的特征计算 batch100→1，保留两 TopK／100 个整人候选／14 关节和 epoch442 参数。FP32 完整 7824 帧对照的 MPJPE 差为 +9.78e-8 mm；29 样本 ONNX 导出核验通过。随后 FP16 Icraft 图在 Lite 首帧完成推理，分数逐位一致，姿态 78/4200 个坐标不同，最大关节偏差 1.953125 mm、该帧 MPJPE +0.004211426 mm，原逐位门禁按当时规则正确停止。原失败、原始输出和模型身份保留在[原报告](../tools/pose-v1/evidence/shared-graph-board-20261015-r1/REPORT.md)，不能重写为原门禁通过。

用户认为偏差可忽略并要求放宽门检、记录问题，随后明确指定：**“最大误差可以定在3mm以内”**。采用这一工程容差决定，不再要求该共享候选的姿态与旧图逐位相同。

用户提出“算法结构改变使 NPU 内部硬件产生物理变化及物理偏置”作为解释。当前只验证了计算图／矩阵形状／生成指令变化及结果差异，BOOT、SDK 与器件未替换；没有物理结构、固定偏置来源或重复统计的证据。故项目记录为：**共享计算改变低精度执行形状后的数值差异，具体产生步骤未定位；物理偏置是未验证假设。** 用户接受该幅度误差不等于完成根因证明。

## 采用的门检与适用范围

| 项目 | 规则 |
|---|---|
| 姿态 | 同一候选槽位、同一关节，三维欧氏差 `sqrt(dx²+dy²+dz²) × 1000 ≤ 3.0 mm`；覆盖全部 100×14 关节 |
| 分数 | 全部 100 个 FP32 分数字节逐位原冻结参考 |
| 输入 | 全部 10800 个预处理 FP32 逐位原冻结参考 |
| 有限性 | 实际值及参考值必须有限，NaN／Inf 立即停止 |
| 其他停止条件 | 非法索引、SDK 异常、身份变化、超时、内核日志变化等原规则保持 |
| 保存及候选身份 | 先保存完整实际值，再比较；不排序重匹配、不抹去误差、不改输出／参考 |
| MPJPE | 继续按原方法报告实际增量；用户本次只明确了 3 mm 最大偏差，没有新增 MPJPE 硬阈值 |
| 范围 | 只适用以下固定共享 FP16 JSON／RAW；不推广为其他模型、训练误差或旧 DATA 异常的容错 |

3 mm 定义为关节向量长度而非每个轴各 3 mm，从而避免三轴组合偏差大于 3 mm 仍通过。上限含等号，比较在 double 中计算，不再量化或舍入后比较。门检模块的“matched”表示符合新数值标准，同时日志分别保存 scores／poses 的逐位状态。

固定模型：

- JSON SHA256：`a1395205eed11112ac0e23dacf8eec4c09d7dfec120e99b060a9361cb9c812cc`
- RAW SHA256：`d235ec300f2872f1b78ce6101bc98fd2cc13c47a53fe99f76e045587148279dd`
- 模型及实际 TOML：`model/piw24_shared-20261015-r1`，ZG330／FP16／4×4／1 core。
- 可机读政策：[policy.json](../tools/pose-v1/evidence/shared-gate-policy-20261015-r1/policy.json)。

## 实现、核验与证据

门检独立实现为 [shared_output_gate.hpp](../tools/pose-v1/shared-output-gate/shared_output_gate.hpp)，不修改数学核、模型、预处理、SDK 同步或正式演示。新独立诊断入口调用此模块；保留旧源码、旧二进制及原失败 Session，不将本次源码回写到原证据包。

12 组本机边界与拒绝检查已实际通过，包括末候选末关节、三维对角超限、恰好阈值、阈值外、极小分数差、NaN／Inf、非法阈值。对已保存首帧离线复核，最大关节差 1.953125 mm，符合新 3 mm 上限；这是新政策下的重新评估，不改变当时 exit1 的事实。

本次新板测沿用原计划三窗口与 120 秒子进程预算，采用独立目录 `/tmp/wifi-pose-shared-gate-20261015-r1`、新包和新 Session。任何新门禁失败仍立即停止，不自动重试或增加负载。最终实际执行、各窗数值及耗时、完整原值和回收状态以[本次报告](../tools/pose-v1/evidence/shared-gate-policy-20261015-r1/REPORT.md)为准，不能将脚本或编译完成视为板测通过。

实际复验：三窗全部执行，308／309最大关节差均1.953125mm，通过；310最大单坐标差3.90625mm、最大关节差5.524271728mm，唯一超限位于候选24／关节4（从0编号），按新门禁exit1停止，未重试。三窗输入／全部分数逐位、全部输出有限，平均MPJPE变化−0.005315145mm；均值不豁免最大误差超限。Engine三次实测32.90414／27.31461／23.29739ms，描述均值27.83871ms包含拒绝样本，不是验收通过的性能基准。前后SDK／BOOT身份相同，无本批后台，FPGA operating，FPAI恢复停止。

## 影响与限制

允许该固定候选存在 3 mm 范围内的关节偏差，原逐位要求变为有界数值要求。它有利于验证已获用户接受的共享改造，但不能保证任意样本精度不变，也不能据三个窗口建立完整数据集、长期稳定性、整机吞吐或“物理偏置”结论。原旧 DATA 首次坏读调查继续暂停；正式基线的异常证据、停止条件和模型保持。
