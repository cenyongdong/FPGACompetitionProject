FPGA 做硬件加速（初步构想，不代表项目主流方案）：

#### 杀手锏 1：【FPGA 硬件 CSI 预处理加速 IP】（消灭 5.66ms CPU 耗时）
* **现状**：目前相位计算（`atan2`）、相位解缠绕（Unwrap）和最小二乘法去倾斜是在 ARM CPU 上跑 C++ 代码，占了 **5.66 ms**；
* **FPGA 改造方案**：
  * 在 PL 端用 Verilog 或 HLS（高层次综合）写一个专用的 **CSI 预处理流水线 IP 核**；
  * 利用 FPGA 内部自带的硬件乘法器（DSP）和 **CORDIC 算法 IP**（硬件级超快三角函数与相位解算）；
  * **效果**：数据从网口一进来，FPGA 在硬件流式传输中边过边算，**只需 0.1 毫秒（100 微秒）瞬间算完预处理**！比 CPU 快 **50 倍**，且 CPU 占用率直接归零！

#### 杀手锏 2：【FPGA 硬件 TopK 协处理器】（消灭拖慢整机的 157ms！）
* **现状**：还记得前面导致系统只能跑 5 FPS 的最大元凶吗？就是 `TopK` 和 `ScatterND` 这两个算子，导致 NPU 和 CPU 来回倒腾，耗费了整整 **157 ms**！
* **FPGA 改造方案**：
  * 用 Verilog 写一个并行的 **硬件 TopK 排序树 IP 核** 挂在 AXI 总线上；
  * NPU 算完后，不需要甩锅给孱弱的 CPU，直接把数据递给这个 FPGA 硬件排序器，**几个微秒内瞬间排好前两名**！
  * **效果**：把这 157ms 的等待直接干掉，整机帧率瞬间从 5 FPS 暴拉到 **30~50 FPS**！
