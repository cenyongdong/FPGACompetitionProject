# ADR_04：固定部署基线、独立参考与训练旁支隔离

- 日期：2026-10-08；状态：首版基线和现有27样本数值阶段获用户验收；训练退化/人工边界仍未解决。
- 决策：首版继续2024 epoch442，PC与板端使用同一真实CSI契约。以独立ONNX直接对照板端，Icraft全CPU Matmul缺口不阻断部署对照。训练实验不混入首版模型。

## 难点、解决与剩余问题

| 问题 | 已采用处理/证据 | 结论边界 |
| --- | --- | --- |
| CSI转张量的相位/解缠绕/去倾斜和位模式可能不同 | PS逐步复现训练预处理，固定真实输入/参考，300份原始CSI和10,800FP32每窗逐位核验 | [300份结果](../tools/pose-v1/RESULTS-300.md)。人工±π诊断仍有2.333111/2.693437rad误差，用户降为非阻断；不能宣称所有边界数学等价 |
| Windows Host工具/板端全CPU Matmul注册缺失，参考路线阻塞 | 独立Conda环境Python3.10.21、NumPy2.2.5、CPU ORT1.23.2，依赖/模型/输入/输出哈希锁定，CPU provider顺序单线程，重复首样本 | [ONNX结果](../tools/pose-v1/ONNX-REFERENCE-RESULTS-20261006.md)。不修改Icraft环境，不将ONNX成功当板端通过；Matmul保持NPU |
| 100候选排名微变，同槽姿态误差大 | 保存全部分数/14×3坐标，对27窗＋重复报告最大/均值/RMS/P95、同槽和各端最佳候选分别比较，不重排原误差 | [运行结果](../tools/pose-v1/RUNTIME-RESULTS-20261007.md)。同槽坐标最大2.77697、最佳2.67562模型单位；S52_18_317前两名交换支持排名推断，跨端query身份未证 |
| 用户认为可验收，但误差原因没有完全证明 | 记录2026-10-07用户批准现有27样本部署数值阶段，不将其判断改写为数学证明 | PC/板端模型输入已逐位一致，不能归因已证实的数据传输损坏；无物理标定/真实标签/MPJPE或全测试集泛化验收 |
| 26版迁移分支初始化、梯度和论文细节不明确 | 独立14残差分化/3层细化模块、哈希迁移映射、STE和梯度/DDP门检；注意力正常初始化，坐标末层零初始化并检查更新后梯度 | 10轮最佳122.87380mm对旧123.08535mm仅改善0.21155mm，细化非稳定获益，单seed不可宣称架构提升。证据见[Done训练旁支](../Done.md)及tools/pose26-transfer/20261003 |
| 全新500轮仍走迁移初始化，随后分支衰退 | 独立注册类绕过旧migrate，并禁止checkpoint读取验证全新初始化；保留用户指定Adam配方，诊断参数/梯度/分支幅度并严重退化停机 | 实际第6轮末Persistent branch collapse停止，只有5轮完整评估，最佳420.18995mm。L2衰至7.44e-38及梯度0；耦合L2/裁剪等因果尚未唯一证明。未恢复/换优化器，500轮不算完成 |

## 后续方案

实时新CSI、泛化/人数与候选匹配、人工边界修正、训练消融分别建立新门检和决定。现阶段优化必须保持固定输入及全部输出回归。不得把训练健康门检、损失下降、部署数值用户验收相互替代。
