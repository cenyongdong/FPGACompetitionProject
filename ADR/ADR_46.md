# ADR_46：执行规范、进度、难点与历史过程分开维护

- 日期：2026-10-13。
- 状态：用户要求整理文档，本轮已实施；不涉及源码或设备变更。
- 决策范围：文档职责和历史迁存，既有技术决策及测试结论保持。

## 问题与影响

Agents.md约190KB，混入160余项阶段实施、身份哈希、失败现场、暂停/恢复与工具教程。大量相继追加的“当前”会把旧状态、已消耗单次许可与有效规则混合，增加恢复误判风险；PROJECT-PROGRESS与DIFFICULTIES也以批次日志反复更新，读者难以判断最新结论。

## 决策与文档职责

| 文档 | 应保存内容 | 更新方法 |
|---|---|---|
| Agents.md | 代理执行分工、约束、有效授权、审批与暂停、代码和证据维护规范 | 同类规则合并，已过期的历史授权/状态迁出；只保留仍影响执行的边界 |
| PROJECT-PROGRESS.md | 单一最新阶段、已完成与未验收、基线入口、管理估计及恢复点 | 更新当前总览，标明最后实际验证日期；不逐批叠“当前” |
| DIFFICULTIES.md | 稳定问题编号、现象/影响、处理与结果、未证假设、ADR/证据 | 沿用D01–D18并补充D19–D30，同一问题更新状态 |
| ADR_XX.md | 一个技术/架构取舍的依据、候选、决策、验证及限制 | 原决策对应结果可补；无关新决策新建文件，不把纯过程塞入旧ADR |
| ADR/history/20261013 | 原Agents过程和旧总览的主题历史 | 保留源行/哈希/历史边界，明确不作为现行指令 |
| Done.md | 已完成工作与后续可复用参考 | 保留既有模板，不重复记同一验收 |
| REFERENCES.md、TechDetails.md、证据目录 | 原资料索引、技术实现说明、原日志/字节/清单 | 各司其职，不用摘要替代原证据 |

## 实施结果

1. 原Agents提炼为执行规范，保留软件/AI一般用户执行、特殊问题代理协助、FPGA代理、主动读文件/板日志等授权及审批边界；不重新请求已有许可，也不扩大历史许可。
2. 独立规整许可保留，旧单次规整约束只是历史；清缓存/再次重启/CMA/BOOT/SDK/模型变更不因本轮整理获得授权。当前DATA排查未明确恢复，不继续。
3. 161项历史记录按演示、读取取证、视频生命周期、混合推理、CPU/SDK、训练、平台七主题存放；工具调用例整体另存历史runbook。纯规范来源提炼，混合规范的历史接续部分另存。原IP/账号放入进度配置，凭据不新增到公共历史。
4. 进度总览只描述截至2026-10-11的实测：三/60演示全链通过，57额外样本非完整精度验收，高负载根因、首启动永久可靠性、HDMI/严格5Hz/长期仍待。83/100只作原管理估计，不因文档整理增加。
5. 难点稳定编号明确已解决、有限缓解、未解决或暂停；旧早期“待实现”不覆盖已完成演示，同时保留原阶段全文。既有ADR_00–45不重写、不挪动原失败证据。
