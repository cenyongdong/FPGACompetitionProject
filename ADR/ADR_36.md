# ADR_36：匹配 AXI 读路径责任边界与独立双模式对照

日期：2026-10-11。状态：批准范围已完成，四项双模式对照通过，模型根因未解决。

## 现象与证据

ADR_35 的 inv48 首次 Host 快照已出现 592 个变化值，其中 589 个非整数；CPU 前快照不变，592 个变化值全部逐位等于紧前 DATA 输入相同偏移值。两次晚源读取正确。这支持优先调查读取完成／共享暂存责任，不证明缓存或 DMA 根因。

匹配 AXI 插件 d55e4887…bc7178 的反汇编确认：PL 读分配 16 MiB 暂存块；DMA 读持锁设置传输并轮询状态，再通过暂存 MemChunk 读取 Host，之后解锁。UDMA 读持锁写同步范围及 CPU 同步属性，再 memcpy。不能以“没有锁／同步”解释异常。状态位对应的硬件完成范围、缓存同步与生产者完成的关系、其他写入者的共享所有权仍待证。板端 UDMA 3.2.5、128 MiB、物理起点 0x30100000、非 coherent；仅 sysfs 和二进制证据不替代匹配驱动源码。

## 决策与实现范围

保持 SDK、模型、BOOT、内核、CMA 与已验收推理基线。新增隔离 SDK 公开 API 比较模块，明确 Host 目标身份、类型、容量和非别名；分别调用 copyFrom 和 Tensor::read，复用原严格字节门检，不修补索引、不添加睡眠或第二读作为生产修复。

使用实际 192 两输入 FP32／布局／全有效分布类型，30240 和 16800 字节，公共 SDK 分配器拥有 96 MiB 前缀与两个独立源，前缀不读写。每模式一次 100 对动态不同图案；正常首读结果拥有后比较，仅失败保存两轮晚源作证据。内存对照先行，通过后以原两缓冲、cookie、10 fps SDK 无关 VPU worker 比较。VPU 取得首次实际 capture 后主线程打开 SDK；每对之间 200 ms 有界采样，单对内部不延时、无 NPU／Session。异常停止后回传，不重开。

模块通过最小公开接口协作，不直接读取私有暂存字段、ADDR/BOTH 指针或自写参考寄存器。复用既有图案、VPU 和持久化模块；原 Host107／注册／CPU 数学实现不修改，本轮不重复运行未改基线。

## 验证与限制

新 Host 检查两方法、四代图案、两实际类型及别名／空张量／非法方法拒绝。ARM 构建绑定来源、SDK 头库和图哈希。内存对照、VPU 对照、解码、清理分别记录。旧较高 PL 地址 copyFrom 通过作为历史证据，不能改称新 read 方法通过。

两方法均通过只证明已知 SDK 写入图案的该条件正确，不证明 NPU 生产完成、内部总线顺序或全模型高并发正确。不放宽原 192 整数及完整输出门禁，严格 5 Hz／103／长期仍待。

## 解决与验证结果

隔离r4主程序 b2f7db68…73fec7、Host a1823244…86406c、manifest de0ace33…bf975，25来源。两方法Host四代／两类型376320字节及8拒绝通过；无VPU／合成VPU各两方法共400动态对／4704000 FP32 C++逐位正确，独立NumPy核对400对指纹和实际保存141120 FP32字节。源100667392／100697664、前缀不访问、dtype／布局／分布保留；无模型Session／NPU生产。原CPU两源哈希同，Host107沿用上批记录而非本轮重跑。

两VPU阶段226／229图像及455编码ID／实际PTS／解码内容、正常drain-LAST、STREAMOFF10/9、join后SDK销毁及所有自有块归还通过。四阶段exit0／stderr空，跨阶段最终内核同；普通512KiB单位17／83，规整0。最终MemAvailable714320KiB／CmaFree37544KiB仅现场；项目进程、39001／8554及连接全关闭，无后台。

实际板端UDMA模块78cae710…35436c回传身份匹配，其CPU属性回调具有mutex、范围检查、命令1使用当前范围字段及DMA同步调用，不能再笼统断言软件未同步。网上master不作厂商3.2.5源码证明。copyFrom的XRT跨区域路径额外经中间Host字节区，但读与copy仍共享PL／UDMA底层。现有证据未证明状态退出、NPU输出可见性及锁的所有实例覆盖。

本机r1头名错误打包停止；r2命名空间Bytes／实际char*签名／缩进Werror，r3仍有const签名错误；r4显式依赖及实际接口修正，新目录构建，失败保留。Linux归档权限使原解包树在沙箱内不可读，使用原档案创建不导入权限的readable字节副本并复核；未改原数据。板时钟tar未来提示保留，未修改时钟。原部分反汇编窗口已以符号精确大小补齐，短窗口不承担“缺同步”结论。

当前解决的是匹配实现和两个公开应用读法的独立可验证性，未修复正式模型并发坏索引。没有实际异常，原失败捕获晚源机制未在本轮触发。仍不采用第二读修补、delay、cache helper或私有映射；下一先匹配生产／DMA完成契约，准备最小真实NPU生产者对照或正式责任证据交接。[结果](../tools/pose-v1/AXI-READ-RESULTS-20261011.md)／[下一](../tools/pose-v1/AXI-READ-NEXT-20261011.md)／[完成绑定](../tools/pose-v1/evidence/axi-pair-20261011-r4/completion-review.json)。
