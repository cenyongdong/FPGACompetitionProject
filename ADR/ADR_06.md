# ADR_06：可解释性能测量与隔离应用接口

- 日期：2026-10-08；状态：核心短期5Hz基线、TCP回放和CPU绘图已验证，整机/长期待验。
- 决策：单steady_clock记录实际边界，先低风险优化并保留完整输出，再以独立接口接入应用；不以重复视频计新推理吞吐。

| 难点 | 实施和结果 | 限制/下一取舍 |
| --- | --- | --- |
| profiling和取证混淆性能，ZG异步跨度不能当纯NPU时间 | 原P1平均214.85948ms/4.65420Hz；用户批准profiling-off。单时钟r3平均212.93086ms，桥等待164.48ms、CPU forward29.59ms、可见复制0.47ms | 等待不是全部CPU计算或复制；未证明TopK硬件可直接消除157ms，先完成全流程 |
| 成功检查也预先构造大量字符串 | 隔离lazy-r4仅CPU/验证助手新增const char*重载共4行，检查/计算/SDK调用/同步均保持；37输出逐位旧参考 | [P2结果](../tools/pose-v1/P2-RESULTS-20261007.md)：190.60146ms/P95190.75409/最大190.80669、5.24655Hz。余量约9.4ms只针对核心，不含网络/绘图/编码 |
| 检查器与生产逻辑耦合、未知窗口错误扩大成参考成功 | 独立Engine生产API返回所有候选/输入/计量，冻结检查器保留；单Engine串行，错误后停止；固定三/27窗与旧输出回归 | [应用结果](../tools/pose-v1/APPLICATION-RESULTS-20261007.md)。未知输入接口存在不等于未知场景精度通过 |
| TCP碎片、重复/中断/非法窗口及生产积压 | 完整窗口协议显式长度/身份校验，碎片接收/断线/重连测试，最新完整窗口单槽，未完成数据不发布 | 3/27网络2Hz完整输出通过，receive-result P95约193.76ms只是该条件观测，非整机5Hz或无限连接稳定性 |
| 骨架定义/坐标投影和颜色格式易混入算法 | 固定14关节/BONES/C2翻转/显示投影，保留原模型单位；纯CPU draw和格式转换独立模块，无GT、过滤或候选匹配 | [绘图结果](../tools/pose-v1/RENDER-RESULTS-20261007.md)：Native/ARM/NumPy RGB565/NV12/NV21逐字节27图一致。约11.94ms draw和88.85ms三诊断转换不作单生产NV12性能 |
| 同名全局助手ODR与线程资源归属不明确 | 私有助手匿名namespace；每模块只暴露数据/生命周期契约；Engine同一主线程创建/前向/销毁，VPU独占编码线程 | [ADR_02](ADR_02.md)记录后台Engine非有限失败与r6成功。不能把主线程成功写为SDK内部原因已确诊 |
