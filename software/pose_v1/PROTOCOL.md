# 原始 CSI 窗口契约 v1

回放客户端只发送原始数据，不访问 GT、预处理模型输入或生成预测。

一条记录是32字节固定头部＋86400字节负载；全部数值采用 little-endian。

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | 8 bytes | `PIWCSI1` 后跟一个 NUL |
| 8 | uint32 | 版本，固定为1 |
| 12 | uint32 | 原始负载字节数，固定为86400 |
| 16 | uint64 | 回放帧号 |
| 24 | uint64 | 发送端时间戳，纳秒；0表示未提供 |
| 32 | float64 pairs | `[3 receiver,3 antenna,30 carrier,20 sample,2 I/Q]`，C序连续排列 |

每个复数为两个 float64：先 real，后 imag。MATLAB HDF5 `csi_out` 形状
`[20,30,3,3]`、real/imag字段，按原训练读取方式 transpose(3,2,1,0)。
负载保留原始幅值和精度，不做归一化或子载波挑选。

预处理输出：little-endian float32 `[1,180,60]`，按receiver→antenna→time排列180个token，
每token为30个幅度＋30个校正相位，共43200字节。

接收端必须按记录长度重新组包，不能认为一次TCP recv是一帧。非法版本/长度、非有限数、
中断的记录须拒绝，不作为新骨架。跨设备时间戳未经同步不能直接用于端到端延迟；
板端延迟从完整窗口到达后的本地单调时钟开始统计。

当前C++已实现单窗口文件读取和预处理；TCP板端服务、混合推理、队列、HDMI和RTSP尚未实现/验收。
端口39001是回放客户端默认值，后续服务必须使用同一契约。当前不应向板端启动回放客户端。
