## 近期显示问题复盘（离线分析，未修改算法或启动板测）

用户要求先分析和讨论。检查 r1 实际展示捕获、同源 v1／v3 回放及 r2／r4／r5 最近原始环；新统计在 [analysis.json](../../../.local/pose-presentation-analysis-20261026/analysis.json)，可用同目录 `analyze.py` 复算。`--prepare` 从旧证据包读取原始环并调用现有原生 `pose_replay.exe`，不访问设备。最新环的 CPU 回放不等于当时完整 HDMI 录像，首帧缺少前序状态，记录丢弃与保留范围也限制推断；r4 有一个序列缺口。用户离开后的 r4／r5 无人数真值，不把多目标直接认定为误检，不用不同场景的数量比较证明版本优劣。

### 已见证的问题

1. **同 ID 的平滑指标遗漏了换 ID 的画面跳变。** r1 实际展示捕获为 222 帧／26.087 秒，共出现 30 个显示 ID；现场用户反馈只有一人，但没有逐帧身份标注。1829→1830 帧序号连续、同一代次、源时间间隔 66.771 ms，旧暂失 ID 430 换为新 ID 433，显示骨架中心移动 0.968 模型单位。2007→2008 还有一次 0.923 模型单位的替换。不能称为米，也不能从无真值坐标推断真实行走速度。当前 v3 在 r5 留存环的 CPU 回放中也出现 2496→2497，ID 91→95、66.994 ms 内显示中心改变 2.337 模型单位；旧同 ID 大于 0.5 的跳变统计仍为零。后者说明度量盲区，不证明两个 ID 属于同一真实人物。
2. **暂失姿态与新目标共存是重影的重要来源。** r1 实际展示捕获中有 36 帧显示两／三人，共 44 对同时显示骨架，其中 33 对至少一方为暂失。1980 帧新 ID 471 与暂失 133.762 ms 的 ID 464 同屏，中心距离为尺度的 0.198、相对骨架 RMS 为尺度的 0.226。旧去重规则未消除这一对。最新 v3 回放仍见相似边界样本：r4 的 2522 帧中心／形状距离为 0.463／0.211；r5 的 2464 帧为 0.720／0.194。它们分别略超过形状 0.2 或中心 0.7 的平移副本门限，不能据此直接放宽成无条件合并。
3. **统一提高确认次数会加重漏显。** 同一 122 帧 v1→v3：双骨架帧 41→24、空显示 15→38、出现过的 ID 18→10；有原始合格候选但无显示的帧 13→31。两版同时改变了去重及确认规则，不能将全部差异归因于单一参数。平均确认延迟约 107→180 ms。r5 最近 212 帧的 v3 CPU 回放中，48 帧为空，其中 46 帧仍有 Top3、严格大于 0.2 的原始候选；这是确认／关联状态需要审视的证据，不能把这些候选都当作真实人。
4. **存在滤波之外的输入间断。** r5 完整实板统计有 6 次重同步、最大结果间隔 3093 ms；r4 为 5 次／3283 ms。250 ms 以后隐藏旧姿态是当前正确性边界；把保持时间拉长到数秒只会掩盖输入失联。源时间间隔、结果返回间隔、归档缺口须分别统计。

### 代码机制与待验证推断

- 轨迹失效与显示暂存共用 250 ms；失效后重新确认并直接初始化滤波器，因此跨身份替换没有滤波过渡。同一人物是否被拆成多个 ID，需要结合现场／标注验证，但这一机制确实可产生“消失后远处出现”的画面。
- 候选先按单帧分数去重，后做轨迹关联；被删候选无法再利用历史连续性。已确认与待确认轨迹共同参与最大匹配数优化，没有明确的已确认优先级。这两项是候选切换／关联歧义的可疑来源，尚未对每次跳变建立因果归属。
- 显示层去重只隐藏骨架，不结束隐藏轨迹；状态变化后它可能再次显示。当前观测优先于暂失，可随观测归属改变而切换显示代表。全蓝配色按用户要求保留，但已无法用原来的灰色区别暂失骨架。
- One Euro 对大导数提高截止频率；大跳点一旦被关联接受，滤波会更快跟随。减小截止频率不能补救错误人物关联，反而会增加正常运动延迟。独立坐标平滑也不等于人物级稳定。

### 分析时提出的候选方案（后续实施见下）

1. **先修候选和身份选择。** 在原 Top3／严格大于 0.2 范围内保留候选组供关联选择，以近期运动／形状连续性和稳定代表选择候选，分数仅作部分依据；先为已确认轨迹匹配，再处理新目标。对歧义关联允许暂缓，不为最大匹配数强行接受弱匹配。避免无条件扩大空间合并范围，必须保留多人靠近／交叉测试。
2. **分开新目标准入、短失联身份保留、显示有效期。** 比较当前三次连续确认与有界时间窗口内“三帧至少两帧”确认，并同时加强新目标独立性与一致性要求，不能仅降低次数。尝试同一代次中保留 500～800 ms 的隐藏轨迹身份，显示仍最多使用 250 ms 内的真实末次姿态；超时隐藏、不外推，不跨恢复代次复用身份。只有通过严格再关联才复用 ID。对被判断为同一目标替代的新确认姿态与旧暂失姿态实行显示互斥，空间近邻本身不足以判同人。
3. **最后调整滤波。** 先加入更稳健的中心速度估计及异常观测门控，再比较中心与相对骨架分开平滑；维持无强制骨长修正、不改模型坐标。所有骨架仍为蓝色；如需显示暂失区别，可讨论蓝色透明度或虚线，不默认恢复文字诊断。
4. **独立处理连续性和验收盲区。** 不用长期冻结画面掩盖输入间断。下一轮同源离线比较须同时报告可见率、重叠配对及暂失占比、跨 ID 的画面位置替换、轨迹重建、首次确认延迟、稳定同 ID 抖动与运动滞后。新指标属于画面现象，不能冒充身份准确率。保留每个阶段有界原因记录，区分阈值无候选、确认不足、关联拒绝、重复抑制、身份超时及输入重同步。

推荐先用 PS 离线完成上述候选／生命周期实验，再决定部署。实测单人 PS 浮点滤波仅约 6.4 μs，当前视觉问题不由该计算量解释；现有 PL 可以继续承担数值滤波，新增资源或并行度不会自动修复身份及误检。若需要明确的单人展示模式，可独立设计目标锁定，但不把默认强制 Top1 当作多目标问题已解决。
