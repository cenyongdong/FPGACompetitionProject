2026-10-25。**r6已完成获准的10分钟真实CSI→新推理→HDMI验证、正常停止及原BOOT回退，包已关闭、全部余额0。** 同一TX任务完成61次续期且无续期失败；新版HDMI视角、大小、颜色及更新获现场确认。仍有约11秒的组窗等待后恢复，不能认定整体卡顿已经改善。r5及更早包保持关闭。

## 行为与接口

原mode2每60秒耗尽18,000槽，结束后经用户态释放、配置和启动形成任务间隙。新增mode3保留300Hz的3333／3333／3334µs绝对节拍，同一上下文和定时器持续运行，以60秒固件租约约束后续发送。TX本机守护每10秒续期，不依赖PC、SSH会话或板端结果回执；退出、故障或失联不会自动创建新的发送任务。原mode2有限测试继续保留。

共享定义见[tx_lease_protocol.h](../../../tools/nexmon/router/tx_lease_protocol.h)，固件生成器见[prepare_tx_task.py](../../../tools/nexmon/environment/prepare_tx_task.py)，守护见[router_guard.c](router_guard.c)。全部新增控制字按little-endian传递，不改变无线帧、RX的CSI／NMD3或PIWFUL3。

| 操作 | 契约 |
|---|---|
| 429配置／430启动 | mode3只允许300Hz、初始60秒预算；配置产生非零任务token。运行中拒绝429覆盖，旧token不能续新任务 |
| 434续期 | 12字节：magic、token、非零递增seq。只接受同一健康且尚未到期的运行任务，把期限更新为当前TSF＋60秒；不累加无限预算，不修改next_due、fraction、running或定时器 |
| 435租约状态 | 32字节：magic、version、token、已接受seq、剩余毫秒、running、error、续期次数。配置后未启动时可取得token；radio-down时不读取TSF寄存器 |
| 433诊断 | 原48字节v1保留；mode3剩余槽仅按租约估算，提交计数仍不证明实际空口发送完成 |
| 431停止／432释放 | 停止状态保持，迟到续期或430不能复活。mode3运行中拒绝432。守护先431，再435核对同token且已停，最后432；成功后写tx.released，恢复脚本不重复释放 |

固件期限使用对齐的volatile 32位字段发布，定时器只读取，避免续期和每槽扣减共享预算的读改写竞争。停止标志保持有效，即使续期在停止附近完成也不会恢复running。每次发送前检查期限、无线状态与时钟连续性；分配skb期间恰好停止／到期时，释放尚未提交的skb。分配失败、无线down、过期和异常时钟跳变停止当前任务，保留错误码。

正常TSF低32位回绕使用模差处理；一次超过60秒的回调间隔按失效停止。跳槽先按完整10ms／3槽周期计算，再处理最多3个余数槽，不突发补发。累计提交计数回绕不重写首次入队时间。定时器取消／释放继续沿用目标固件已有的wl_del_timer→wl_free_timer→free路径；native模拟不证明真实固件调度并发或无线队列排空。

守护每秒核对435身份与运行态，每10秒续期并核对回执，433诊断每10秒一次。续期返回失败、超时结果未知、token／seq变化或停止状态均结束受影响发送，不盲目重试。缺少停止证明时不直接free，交原无线恢复路径。日志仍最多两段×64KiB，状态固定覆盖；新增续期次数、失败次数和停止原因。正常运行只配置／启动一次，去掉租约模式的单轮65秒超时，保留整包总期限和独立看门狗。
