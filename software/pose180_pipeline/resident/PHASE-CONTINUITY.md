# 时间分支连续性修正与离线推理对照

2026-10-27。按用户要求实现可选修正，保留原预处理作为对照，使用已有实采及官方数据集做实际模型前向。**没有恢复现场采集、访问路由器或开发板、运行 SDK、部署或改变 HDMI／PC 画面。**

结论：算法已实现并完成离线比较；**信号分支修正有效，但当前权重的推理效果有改善也有退化，因此原路径继续作为正式默认**。本轮不是实板或画面观感验收，也不是全测试集精度评测。前一轮的原因分析与单 RX 诊断保留在[相位审计](PHASE-PREPROCESS-AUDIT.md)。

## 实现与接口

- [phase_branch.hpp](../../core/input/phase_branch.hpp)／[phase_branch.cpp](../../core/input/phase_branch.cpp)：按物理 RX 跟踪相邻两对天线在首个选定子载波上的相位整数分支。状态按源事件身份推进，不能按推理帧编号推进。
- 原 `preprocess(RawCsi)`、两处原 `preprocess.cpp/.hpp`、模型及 SDK 均保持不变。先执行一次原预处理，再由 `apply_phase_branches` 可选地修正相位通道；未修正通道保持逐位不变，全部幅度保持逐位不变。
- 若两对相位的累计绕圈整数为 `q1/q2`，固定原频率展开及拟合，只为三天线选取 `(0,q1,q1+q2)×2π` 的常量分支；公共截距对应的最终旋转为 `−2π(2q1+q2)/3`。只需保存模 3 状态，避免长时整数累积。没有低通、插值或按姿态真值改 CSI。
- 源身份为 `(epoch, extended_sample, own_RX_time_ns)`；不跨 RX 相减时钟。每 RX 缓存最近 128 个事件的不可变提示，重叠窗口复用而不重复推进。超过缓存的旧事件须显式重置后重放，不能悄悄解释为新事件。
- 默认源间隔超过 10 ms、新 epoch 或首载波任一天线参考幅值小于 `1e-12` 时重锚。10 ms 可由构造参数改变，是断段配置而非姿态验收容限。缺口／未定义相位只重锚推进状态，保留缓存中旧事件的提示，支持跨缺口的窗口重叠；显式源重置清缓存。
- 零幅度载波保留原未定义相位约定；非有限值和身份冲突拒绝处理。真实天线间圆周相位差不被公共旋转扣除；最终 ±π 标量换行仍可能存在。

本实现明确**冻结原频率拟合**，不重新运行带大整数偏移的跨载波 unwrap。与早期“全部载波先沿时间 unwrap 再重拟合”的诊断原型对照，三 RX 实采有效相位差最大 `2.36e-7 rad`；官方样本有 6,553 个有效相位值差异超过 `1e-5 rad`，全体检查量为 6,147,259 个。保留这些数值分支差异，不声称两种实现对任意 ±π／未定义边界逐值等价。本轮模型对照使用实际 C++ 实现生成的张量。

## 实际结果

| 指标 | 原方法 | 时间分支修正 |
|---|---:|---:|
| 测试子集：共同匹配的 847 个 GT 人体 MPJPE | 168.41 mm | 166.86 mm |
| 测试子集：匹配覆盖／全部 GT 人体 | 857／867 | 850／867 |
| 测试子集：按人数少检／多检 | 10／4 | 17／5 |
| 测试子集：人数 MAE／相邻人数切换次数 | 0.0342／27 | 0.0538／40 |
| 训练片段：共同匹配的 867 个 GT 人体 MPJPE | 114.38 mm | 121.62 mm |
| 训练片段：匹配覆盖／全部 GT 人体 | 868／870 | 867／870 |
| 实采：相邻人数切换次数 | 183 | 132 |
| 实采：零人窗口 | 120／447 | 120／447 |
| 实采：相邻匹配姿态变化 P95 | 379.26 mm | 391.09 mm |

测试子集的误差仅略降，漏检与人数切换增加；训练片段误差上升约 7.24 mm。实采人数稳定性变化主要来自 run300-2：125／149 窗输入被修正，单人／双人／三人窗口由 81／38／30 变为 129／15／5；**没有人体真值，不能把人数变少当作人数更准确**。run300-1 和 run300-3 没有触发修正，两方法全部分数／坐标逐位相同。120 个零人窗口未被恢复，相邻姿态变化的 P95 也未降低。

单独检查唯一源事件、排除 >10 ms 缺口，统计天线 0 至少 15／30 载波相邻圆周变化 >0.25 rad 的次数。若干官方段明显减少，例如 S22_01 的 RX1 为 311→116、S52_01 的 RX3 为 81→0；**三 RX 实采中 run300-2/RX3 的 974 次仍为 974 次**。前轮 60 秒单 RX 诊断的减少不能直接替代这三组实际模型输入的结论。

据此保留可选算法与对照入口，不改正式默认。当前权重按原特征生成方式训练，修正改变相位取值分布，这可能参与部分退化，但本次对照不能唯一归因。下一步可在保持两端画面的前提下，用已有数据研究更可靠的异常状态判别及训练分布适配；本轮不启动新训练或现场采集。
