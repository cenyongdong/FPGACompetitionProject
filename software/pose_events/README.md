状态累计要求同来源片段、同运行代次、连续结果序号／采集序号、已验证或明确合成的采集时间、间隔不超过150ms、单人证据及有效几何。未知／跳变／重复／无效输入重置时序，保留尚未确认请求。单个最高分、0.5阈值或有限值检查都不构成人体真实可靠性的证明。

## 模拟PL反馈

`PlSimulator`分别接收服务心跳、输入进度和结果进度；默认服务超时500ms，输入／结果过期300ms。重复序号、旧代次不能续期。初始化没有心跳时不能显示可用；停止／故障不自动重启，也不清除请求。新代次不能用相同数字事件ID误确认旧代次请求。

归档轨迹中的心跳／输入通知由离线适配器生成，使用主机接收时间作为**模拟时间**，并在末尾注入结果过期、输入过期和服务失联。这不是原实验的物理心跳、RF时间或真实PL观测。另一份合成轨迹演示：请求锁存→PS不再更新→500ms服务失联但请求仍保留→故障／新代次仍保留→正确确认后清除。

本模型只验证有限状态和虚拟时间，不验证CDC、寄存器握手、实际引脚、PL时钟独立性、DMA完成或故障安全。没有移用SW6／SW7或接入新的输出硬件。
