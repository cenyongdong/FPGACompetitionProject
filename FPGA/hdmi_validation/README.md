# HDMI 独立诊断与行为验证

本目录保存HDMI专项验证工具，不进入正式推理、绘图、视频或网络模块，不修改 `Docs` 中的参考源码。

- `run.py <rN>`：将参考显示RTL复制到全新 `.local` 目录，用本机XSim2019.1做行为仿真。包含固定扫描频率、读帧背压、VS门控以及参考AXI握手缺陷复现。AXI源有10项重复ANSI端口wire声明，仿真副本仅删除这些声明；原逻辑不改，diff和两种SHA保存。测试通过表示观察/复现符合预期，**不表示参考DUT正确**，也不是Procise实现或实板验收。失败目录不可复用。
- `build_probe.py <rN>`：在已有FPAI／Icraft3.39.0中核对锁定SDK后交叉编译寄存器读取探针。仅支持预设的新目录；原容器必须停止，本批启动后结束恢复停止。后端注册依赖必须保留在ELF NEEDED中。
- `deploy_probe.py`：核对BOOT和六份SDK库，部署一次独立读取探针。设备/icore/frame_ctrl版本通过后才读取其他白名单项；公开SDK生命周期保留，无应用层寄存器写、Session、扫描帧分配、复位、推理或DMA启动。子进程10秒、连接有限时，非零或身份/内核变化停止，不重复负载。
- `observe_owners.py`：只读 `/proc` 与sysfs，核对设备句柄和探针退出。不以“没有进程持有设备”证明PL扫描已经停止。

已执行的目录以 `tools/pose-v1/evidence` 中的日志为准。上述脚本是有限阶段工具，不得把示例调用当成恢复失败负载或更换BOOT的授权。当前SDK探针的部署入口固定r3，已执行，不再运行。
