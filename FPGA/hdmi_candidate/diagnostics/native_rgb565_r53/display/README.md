# r53 single-owner begin/poll HDMI output

Public API: begin_show(const vector<uint8_t>& rgb565,uint32_t id), bool poll_show(), bool pending() const. Existing constructor, verifyMemory(), show(), observe(), close() and destructor signatures remain. This directory is independent; r45 inputs remain unchanged.

- begin_show validates owner/size/ID/current hardware state, reserves only the noncurrent SDK slot, performs the same public synchronous full-frame write, disables the static pattern on first START, and sends exactly one START/FLIP with the original response-generation checks. It then returns without waiting for frame adoption. The caller's RGB565 vector need survive only this synchronous call; SDK frame allocations remain held.
- Deadline anchor is the exact old expression Clock::now()+milliseconds(200), immediately after START/FLIP command() returns; SDK write and command ACK precede this anchor. It is never renewed by a poll or inference.
- poll_show performs one original SNAP/healthy transaction on the same owner thread. False means no new adoption (or no pending submission); true means this pending ID/address has been observed with pending=0, running/PLL healthy and unchanged STOP tag. Old accepted ID/address may persist while waiting; any other pair, faults, unexpected STOP, log/command errors or deadline latch failure and forbid another begin. Current slot/last ID change only after proof.
- A late observed match is rejected at now>=deadline. The r45 implementation actually tested matching ID/address before its timeout branch; this candidate deliberately closes that late-match loophole under the newly specified strict 200ms contract. It cannot infer the physical adoption edge from a late CPU observation.
- show remains begin_show plus poll_show with 1ms sleeps. poll_show does not sleep for adoption, but its CSR command still has the original bounded 200ms response wait. An SDK/CSR stall can therefore delay owner-thread decisions; this is not a hard realtime/preemptive guarantee.
- close still sends one STOP, waits the same independent new stopped-tag/idle/no-reader-pending proof with its original 500ms bound, then frees the two frames. A pending/failed frame can only release its hold via this proof. Fault/PLL state does not block safe STOP. No resubmit, clear, rearm, frame drop, reset, external wire/model/NPU/frequency change or SDK thread is introduced.

Compile production hdmi_output.cpp using this directory before the former display include directory; also provide original hdmi_format.hpp and SDK3.39 headers/libraries. No .cpp is included. Compile adoption_state_test.cpp alone as C++17 with this include directory; it needs no SDK library. Tests model logical slot ownership and supplied observations, not actual SDK or board behavior. Root owns compilation/execution; neither has been run by this source-only task.
